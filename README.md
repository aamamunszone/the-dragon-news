# 🐉 The Dragon News

[![Version](https://img.shields.io/badge/version-1.0.0-blue)](https://github.com/aamamunszone/react-x-firebase)

**A modern, responsive news portal built with React, featuring category-based news, user authentication, and protected routes.**

---

## ✨ Key Features

- ✅ User Authentication (Login & Register)
- ✅ Private/Protected Routes
- ✅ Category-Based News Display
- ✅ Dynamic Routing with React Router
- ✅ Responsive Layout (Mobile & Desktop)
- ✅ News Details Page
- ✅ Context API / Firebase Auth Integration

---

## 🔧 Tech Stack

| Technology      | Purpose                        |
| --------------- | ------------------------------ |
| React + Vite    | Frontend framework & bundler   |
| React Router    | Routing & navigation           |
| Tailwind CSS    | Styling                        |
| DaisyUI         | UI components                  |
| Firebase Auth   | User authentication            |
| News API / JSON | Dynamic or static news content |

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/aamamunszone/the-dragon-news.git

cd the-dragon-news
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run development server

```bash
npm run dev

open : http://localhost:5173
```

### 4️⃣ Build for production

```bash
npm run build
```

### 5️⃣ Preview production build

```bash
npm run preview
```
